Building a site's crew roster

Assign workers to a site and see, before you even save, exactly who's cleared.

On a site's detail page, the Crew roster card lists every worker in your directory with a checkbox. Use the filter box to narrow it by name or title, check the workers assigned to this site, then click Save.

Readiness panel

To the right, the Readiness panel updates live as you check or uncheck roster members or required credential types — before you save anything. For each assigned worker it shows:

  • A Cleared or Blocked pill.
  • Which required types are missing (no valid/expiring cert of that type) if blocked.
  • Which required types are expiring soon, even for an otherwise-cleared worker — a heads-up to renew before it becomes a real problem.

Click any row to jump straight to that worker's profile. Click Export CSV to download the readiness table for a report or a client handoff.

No requirements set yet? Everyone on the roster shows as trivially cleared — there's nothing to fail against. Set requirements first; see Choosing which credential types a site requires.
