Creating your first worker profile

Everything a worker record can hold — photo, contact info, skills, and certifications — and what's required vs. optional.

From the Directory, click Add worker. Only one field is actually required to save a profile: Full name. Everything else can be filled in now or added later.

Personal information

  • Photo — JPG or PNG, square, max 5 MB. Until one's uploaded, the worker shows an initials avatar instead of a placeholder.
  • Title, department, location, phone, email — standard fields. Department is a dropdown of existing departments plus "+ Add new department…" if this worker needs one that doesn't exist yet.
  • Skills — type a skill and press Enter or comma to add it as a chip. These are searchable from the Directory later.

Certifications

Click Add certification to add a row for each credential. Per certification you can set:

  • Name and issuer.
  • Credential type — if your tenant has a credential-type catalog set up (Admin → Credential types), tag the cert with a type so it can satisfy a site's requirements. See Choosing which credential types a site requires.
  • Badge image and certificate PDF uploads.
  • Scan cert — upload a photo of the physical card to try to auto-fill the earned/expiry dates. See Scanning a certificate photo to auto-fill dates.
  • Earned and Expires dates.
  • Verification — source (NCCER / OSHA / state board / other), card number, and a Verified checkbox. See What "Verified" actually means.
A blank Expires date isn't "valid." FieldCred treats a certification with no expiry date as missing — a distinct, neutral status — rather than silently counting it as current. If you don't have the date yet, leave it blank rather than guessing; it'll show up in filters as needing attention.

Saving

Click Save profile. If your plan has a worker-count limit and you're at it, you'll be prompted to remove a worker or request more capacity before a new profile can be created — this is enforced on the server, not just the button.

Adding several workers at once? See Bulk importing workers from a CSV instead.
