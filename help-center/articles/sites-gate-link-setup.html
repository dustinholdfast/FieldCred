Setting up a site's gate link

The one-time step that tells a device which site to check clearance against.

Every site has its own gate link — a public URL, shown on the site's detail page under Site settings, that looks like …/#/gate/your-site-slug. Opening it on a device remembers that site on that device (in its local storage), so every worker badge scanned there afterward shows a clearance banner for it.

Setting it up

  1. Go to Sites → the site → find Gate link in Site settings.
  2. Click the field to select it, then copy it — or print the link as a QR code and post it at the physical gate.
  3. On the tablet or phone that will actually scan badges, open that link (or scan the posted QR) once.
  4. From then on, scanning any worker's badge/QR on that device shows a green "Cleared" or red "Not cleared" banner for this specific site.
Every device needs this done separately. The gate site is remembered per-device, not per-account. A second tablet at the same gate needs the same link opened on it too. To point a device at a different site later, open that site's gate link — it overwrites the previous one — or use "Clear gate site" on the worker record page.

If a device is scanning badges and never shows a clearance banner at all — not even a red one — the gate link almost certainly hasn't been opened on it yet. See Why isn't the clearance banner showing? for the exact symptom and fix.
